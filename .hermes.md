# Split

Hermes desktop project for Reverie Hacks 2026 Software track.

Writable root is this folder only. Do not touch Questify, EchoQuest, Ignite, Orbit Ink, or keeb.

## Build

- Vanilla JS. No npm. No frameworks.
- Public GitHub: https://github.com/ethaenall/split
- Live demo: https://ethaenall.github.io/split/
- Serve locally: `python3 -m http.server 8767`

## Product locks

- The crossing is the product. Manual MARK stays small.
- Camera sits on one mark. UI must say FINISH or 200.
- Default demo: FINISH + 800, goal 2:07.04.
- Times are M:SS.xx. No coach AI.
- City only on public pages (Sammamish). No home address. No birth date.
